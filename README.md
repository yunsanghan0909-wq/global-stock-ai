# GLOBAL STOCK AI

미국·한국 주식시장을 대상으로 뉴스·공시·재무·가격 데이터를 분석하고, 모의투자로 검증하는 교육용 프로젝트입니다.

## 현재 버전

**Phase 1 — 정적 웹 대시보드 골격**

- 다크 모드 금융 터미널 UI
- 시장 지수 카드 (현재는 가상 예시)
- AI 종목 랭킹 영역 (현재는 가상 예시)
- 뉴스 모니터 영역
- 초기 가상 자산 $100,000 표시
- 모바일 반응형 레이아웃

> 중요: 현재 화면의 가격, 지수, 종목 점수는 모두 디자인 확인용 가상 데이터입니다. 실시간 데이터/API 연결 전에는 투자 판단에 사용하지 마세요.

## GitHub Pages 배포

1. GitHub에서 `global-stock-ai`라는 새 저장소를 만듭니다.
2. 이 폴더 안의 파일을 저장소 루트에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, Folder는 `/ (root)`로 지정하고 Save를 누릅니다.
6. 배포가 완료되면 Pages 화면에 표시되는 주소로 접속합니다.

## 로컬 실행

빌드 도구 없이 실행할 수 있습니다. `index.html`을 브라우저에서 열거나, Python이 설치되어 있다면 프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000`으로 접속합니다.

## 보안 원칙

- API 키를 `index.html`, `app.js` 등 프론트엔드 파일에 넣지 않습니다.
- API 키와 비밀값은 백엔드 환경변수로 관리합니다.
- 데이터 제공자의 무료 플랜·호출 제한·표시 및 재배포 라이선스를 확인합니다.
- 이 프로젝트는 모의투자 전용이며 실제 주문을 전송하지 않습니다.
